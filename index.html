    Set how many hours you want for each spider on a weekday and on a weekend day; each column should add up to 24. Pull is actual hours ÷ target for the plan you're editing. The Week tab adds these up across your seven days.

    Export to Google Calendar

    Include

    Downloads aren’t available here. Copy this text into a plain-text file and save it with a .csv ending.

    1. In Google Calendar, make a new calendar for this (Settings → Add calendar → Create new calendar), named something like “Caught in the Web”.
    2. Go to Settings → Import & export, choose the downloaded file, and pick that calendar.
    3. When your plan changes, delete that calendar and import a fresh file. The import is a one-time copy and won’t update itself.
